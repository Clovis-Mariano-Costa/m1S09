# Exercícios — 25/09 (Validação de formulários)

Cada exercício é uma pasta própria — abra com o Live Server do VS Code. `01-validacao-nativa/` não tem
`script.js` (é só HTML); os demais têm `index.html`, `style.css` e `script.js` comentado linha a linha.

| Pasta | O que pratica |
|---|---|
| `01-validacao-nativa/` | `required`, `type="email"`, `min`/`max` — o navegador valida sozinho, sem JavaScript |
| `02-validacao-javascript/` | Regra que o HTML não sabe validar sozinho (senha mínima) + `if`/`return` |
| `03-feedback-classlist/` | Simetria do `classList`: cada ramo adiciona a sua classe e remove a oposta |
| `04-formulario-vaitorcer-completo/` | Junta as duas camadas de validação + feedback visual num único formulário |

Ordem sugerida: siga a numeração — a pasta 4 combina tudo o que as pastas 1 a 3 ensinaram
separadamente.
