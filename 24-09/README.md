# Exercícios — 24/09 (Integrando formulários com JavaScript)

Cada exercício é uma pasta própria, com `index.html`, `style.css` e `script.js` — abra com o Live Server
do VS Code. Os comentários dentro de `script.js` explicam linha a linha o que o código está fazendo.

| Pasta | O que pratica |
|---|---|
| `01-submit-preventDefault/` | Escutar o `submit` do formulário e usar `evento.preventDefault()` |
| `02-capturando-texto/` | Capturar texto, e-mail e `textarea` com `.value` e montar um resumo |
| `03-capturando-checkbox-radio/` | `.checked` para checkbox, `:checked` para radio, `null` quando nada está marcado |
| `04-evento-input-contador/` | Diferença entre o evento `input` (a cada tecla) e `change` (ao confirmar) |
| `05-exercicio-de-aula/` | Exercício de aula: junta 01+02+03 no formulário completo do dia 22/09, com resumo do pacote na página (bônus: "Nenhum extra selecionado") |

Ordem sugerida: siga a numeração — cada exercício usa o formulário do exercício anterior como base.
