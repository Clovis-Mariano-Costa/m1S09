# Exercícios — 22/09 (Formulários HTML)

Cada exercício é uma pasta própria, com `index.html` e `style.css` — abra com o Live Server do VS Code
(botão "Go Live"). Nenhum exercício de hoje usa `script.js`: o foco do dia é só a estrutura do
formulário em HTML.

| Pasta | O que pratica |
|---|---|
| `01-form-basico/` | A tag `<form>`, `<label>` conectado ao `<input>` pelo `for`/`id`, botão de envio |
| `02-tipos-de-campo/` | `type="email"`, `password`, `number`, `date`, `tel` + `required`, `placeholder`, `maxlength` |
| `03-checkbox-e-radio/` | Escolha múltipla (`checkbox`) x escolha única (`radio` com o mesmo `name`) |
| `04-select-textarea-fieldset/` | Lista suspensa (`select`/`option`), texto longo (`textarea`), agrupamento (`fieldset`/`legend`) e `:focus` |
| `05-exercicio-de-aula/` | Exercício de revisão: formulário de orçamento da agência VaiTorcer juntando tudo (tipos de campo, `required`, checkbox/radio, select/textarea/fieldset) |

Ordem sugerida: siga a numeração das pastas — cada uma usa o que a anterior já ensinou.
